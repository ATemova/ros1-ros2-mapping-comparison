# Paper figures and tables

Generated by `metrics/paper_figures.py` from the batch reports in
`results/reports/<tag>/report.json`. Don't edit the files by hand. Regenerate them:

```
make report TAG=<tag> GROUP_BY=stack
make paper-figures TAGS="<tag> <rmw_tag> <distro_tag>"
```

| Output | Content |
|---|---|
| `tables/<tag>.tex` | booktabs table: mean ± 95% CI per group, difference to the baseline (%), Mann-Whitney p (Holm-adjusted for 3+ groups), Cliff's δ, Kruskal-Wallis p for 3+ groups. Two groups → `table`, more → `table*`. |
| `figures/<tag>_<metric>.pdf/.svg` | Per-run values per group (box + points), single column (3.5 in). |
| `figures/<tag>_overview.pdf/.svg` | Up to 8 metrics side by side, double column (7.16 in). |
| `figures/<tag>_effects.pdf/.svg` | Cliff's δ for every comparison and metric; filled = p < 0.05, grey band = negligible (abs(δ) < 0.147), dotted = medium/large thresholds. |
| `generated.json` | Which report each output came from, with its SHA-256. |

In LaTeX:

```latex
\usepackage{booktabs,graphicx}
\input{tables/<tag>.tex}
\includegraphics[width=\columnwidth]{figures/<tag>_effects.pdf}
```

Options (`python3 metrics/paper_figures.py --help`): `--metrics a,b` for an explicit metric
list (default: a curated set of headline metrics present in the report), `--all-metrics`
for every metric in the table, `--name` for the output name, `--caption`, `--no-float`
(only the `tabular`), `--formats pdf,svg,png` and `--tables-only` (no matplotlib).

The same report always gives byte-identical files, so a regenerated figure only shows up
in a diff when the data changed. Commit the generated files that the paper uses.
