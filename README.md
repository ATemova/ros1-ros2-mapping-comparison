# ROS1 vs ROS2 Mapping Comparison

This repository contains experiment scripts and configuration files used in the paper:

"A Practical Comparison of ROS1 and ROS2 Mapping Pipelines on a Real Mobile Robot"

## Overview
The goal of this project is to compare mapping pipelines implemented in ROS1 and ROS2 using identical hardware and experimental conditions.

## Repository Structure
- `ros1/` – ROS1 launch files and parameters
- `ros2/` – ROS2 launch files and parameters
- `experiments/` – Scripts for running experiments
- `metrics/` – System metric collection scripts
- `results/` – Raw and processed experiment data
- `plots/` – Scripts for generating figures
- `paper/` – LaTeX source of the paper

## Reproducibility
All experiments were conducted on a real mobile robot. Configuration files and scripts are provided to support reproducibility using similar hardware.
